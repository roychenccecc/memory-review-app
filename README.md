# 自适应复习与错题管理器

一个本地优先的网页版复习工具，用来记录学习内容、错题、知识点树和每次复习结果，并根据记忆分、错题情况、知识点重要性和考试日期安排复习。

## 使用方式

### 在线使用

可以直接打开 GitHub Pages：

```text
https://roychenccecc.github.io/memory-review-app/
```

数据仍然保存在当前浏览器本地，不会因为用了 GitHub Pages 就上传到服务器。电脑、iPad、iPhone 或不同浏览器之间不会自动同步，换设备前请先导出 JSON 备份。

### 本地使用

如果只需要普通记录和复习功能，可以直接双击 `index.html` 打开，或用静态服务器打开。

如果需要“同步到苹果日历”，推荐用内置本地同步服务器启动：

```bash
cd memory-review-app
node server.js
```

然后打开：

```text
http://127.0.0.1:4173/
```

## 主要功能

- 新增学习记录，可标记为“新学”或“复习”，并自动生成复习任务。
- 新增错题，支持题目位置、题干、答案、错因和图片；图片可以选择文件，也可以直接粘贴截图。
- 学习记录和错题创建后仍可编辑，可继续补充备注、修改标签、分类和错题内容。
- 今日页分开显示“待复习”“今日已复习”和“未来复习计划”，已复习内容不会继续混在今日待办里。
- 今日已复习记录可以修改百分比和备注，误填时不会额外新增复习次数。
- 学习记录和错题条目会显示已复习次数、当前记忆分、下次复习日期和关联知识点。
- 支持 JSON 完整备份/恢复、CSV 导出、ICS 日历导出。
- 支持把当前复习提醒同步到本地苹果日历订阅源。

## 知识点树

- “知识点”页以思维导图形式展示知识点树，支持展开/收起、搜索、缩放和内部滚动。
- 新增学习或错题时，可以从已有知识点树中选择标签，也可以直接新建普通标签或树状知识点。
- 支持整条链新增，例如输入 `数学-数字-1` 会一次创建 `数学 > 数字 > 1`。
- 知识点可以设置重要性：非常重要 / 高 / 中 / 低。
- 每个知识点节点会显示综合记忆分；没有可计算内容时显示“暂无记忆分”。
- 有错题的知识点会显示 `错题 n`，点击后跳转到错题库，并筛选出该知识点及所有子知识点关联的错题。
- 知识点树节点可重命名、切换重要性或删除；管理知识点入口在“管理知识点”弹窗中。

## 复习与记忆分规则

- 初始复习间隔：`1 / 2 / 4 / 7 / 15 / 30` 天。
- 每次复习用滑动条或数字输入“记住百分比”，本次分决定是否前进或缩短间隔。
- `70%` 以上进入下一档；`50%-69%` 保持或略缩短；`30%-49%` 明显缩短；低于 `30%` 明天复习。
- 学习记录的记忆分：取最近 10 次复习百分比的平均值。
- 错题的记忆分：最新一次复习占 50%，其余最近记录平均占 50%；只有一次复习时直接使用本次百分比。
- 记忆分会随时间轻微衰减，长期不复习会慢慢下降。
- 历史综合分会做保护性修正：长期薄弱内容即使本次及格，也会保持较高优先级。
- “新学”学习记录会比普通“复习”记录有更高排队优先级。
- 重要性和错题主要影响任务排序、考前重点和知识点综合分，不再直接压缩复习间隔。
- “延后1天”会从当前实际计划日期向后移动一天；今日或逾期任务延到明天，未来任务不会被错误提前。撤销延后会恢复点击前的日期。
- 每日复习上限默认 6 条；超出的任务会按优先级自动顺延到后续日期，日历导出也使用顺延后的日期。
- 设置全局考试日期后，系统会持续排复习任务到考试前；考前重点只加密记忆不牢、重要或久未复习的内容。

## 知识点综合分

知识点综合分是实时计算的，不会额外写入数据库。

- 叶子知识点会分开计算学习分和错题分。
- 学习分：直接关联该知识点的学习记录记忆分平均值。
- 错题基础分：直接关联该知识点的错题记忆分平均值。
- 错题数量惩罚：每道错题扣 3 分，最多扣 18 分。
- 同时有学习和错题时：`综合分 = 学习分 * 60% + 错题分 * 40%`。
- 只有学习或只有错题时，直接使用对应分数。
- 父级知识点只由直接子知识点加权平均，不混入自身直接关联内容。
- 父级加权权重：非常重要 `5`，高 `3`，中 `2`，低 `1`。
- 首页“记忆薄弱知识点”和任务优先级会参考知识点综合分，错题多且掌握不稳的知识点会更容易被提醒。

## 苹果日历同步

苹果日历同步需要用 `node server.js` 启动本地同步服务器。

1. 打开本地地址 `http://127.0.0.1:4173/`。
2. 在网页“设置/导出”里点击“同步到苹果日历”。
3. 首次使用时，打开苹果日历，选择“文件 → 新建日历订阅”。
4. 输入订阅地址：

```text
http://127.0.0.1:4173/calendar.ics
```

以后每次新增学习、错题或复习结果后，再点一次“同步到苹果日历”，苹果日历会在下次刷新订阅时读到最新提醒。

## 数据与备份

- 数据保存在浏览器本地 IndexedDB 中，不登录、不上传网络。
- JSON 备份包含学习记录、错题、图片、知识点、记忆分、复习历史和计划，适合迁移设备或防止数据丢失。
- 应用会在本浏览器内保留最多 6 个滚动恢复点。正常新增、修改、删除后都会自动更新，因此网站升级开始前已经有旧版本留下的可恢复数据；升级成功后会静默补充当前版本恢复点。
- JSON 导入会先完整校验文件，并在一个 IndexedDB 事务中整体替换；任何一条写入失败都会回滚，不会留下“旧数据已清空、导入只完成一半”的状态。
- 如果应用检测到“这个浏览器以前有数据、现在数据库却异常为空”，会停止新增和修改，优先从内部恢复点找回；没有内部恢复点时会要求先导入 JSON 备份。
- 正常的网站版本更新不会强制要求下载 JSON。只有检测到异常空库或本地恢复点写入失败时才会显示警告；非危险警告可以手动关闭。
- 内部恢复点和数据库位于同一个浏览器数据空间，若浏览器配置、网站数据或 IndexedDB 被整体清除，仍只能依靠此前下载到电脑的 JSON 文件恢复。JSON 下载适合换设备、清理浏览器或主动做长期归档时使用。
- CSV 适合放进表格查看，ICS 适合导入日历工具。
- 不同网址来源的数据彼此独立，例如 GitHub Pages、`file://` 本地文件、`127.0.0.1` 本地服务器会被浏览器视为不同数据空间。
- 可以在“设置/导出 → 本地数据保护”查看记录数量、恢复点和浏览器持久存储状态，并手动创建或恢复本地恢复点。
- 建议保留最近下载的 JSON 备份，尤其是在清理浏览器、换设备或切换网址前。
