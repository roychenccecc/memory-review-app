# 自适应复习与错题管理器

这是一个离线本地网页应用，用来记录学习内容、错题、知识点标签，并根据记忆分、知识点重要性和考试日期安排复习。

## 使用方式

推荐用内置本地同步服务器启动，这样可以使用苹果日历订阅同步：

```bash
cd memory-review-app
../tools/node-v24.15.0-darwin-arm64/bin/node server.js
```

然后打开：

```text
http://127.0.0.1:4173/
```

也可以直接双击 `index.html` 打开，或用 `python3 -m http.server` 启动静态页面；但这两种方式不能使用“同步到苹果日历”按钮。

## 主要功能

- 新增学习记录，可标记为新学或复习，并自动生成复习任务。
- 学习记录支持按学习时间查看，也支持按知识树查看知识框架和复习时间。
- “知识点”页就是知识点树，新增知识点时会自动成为可选标签，可设置上级知识点和重要性。
- 新增知识点时可以明确选择“作为新的主分支”或“作为所选知识点的子分支”；下拉按树状从大类到小类显示。
- 支持整条链新增，例如输入 `数学-数字-1` 会一次创建 `数学 > 数字 > 1`，之后可继续在最后一个节点下添加分支，如 `奇数`。
- 知识点树每个节点都可重命名、切换重要性或删除；左侧也有独立删除入口。
- 学习记录和错题表单中已添加的标签会显示成标签片，点 `×` 可从当前记录移除。
- 新增学习记录和错题时都有两种标签入口：普通标签无需分类；树状添加可逐级输入或选择已有分支，点 `＋` 继续添加子标签，误加的层级可单独删除。
- 错题从已维护的知识点树里选择关联知识点，也可以在错题弹窗里直接新建普通标签或树状知识点。
- 标签支持层级和多选，例如 `A知识点 > B知识点`、`题型 > 简答题` 可以同时挂在同一条错题上。
- 新增错题，支持题目位置、题干、答案、错因和图片；图片可选文件，也可点击粘贴区后直接粘贴截图。
- 知识点使用自由标签，可设置非常重要/高/中/低重要性。
- 每次复习用滑动条或数字输入记录记住百分比；当前记忆分按最近 10 次记住百分比的平均值计算，并据此调整下一次复习。
- 今日页会把今日待复习、今日已复习、未来复习计划分开显示，避免未来任务或已复习内容混在今天待办里。
- 设置全局考试日期后，30 天后仍会继续安排复习；考前只加密记忆不牢或重要的内容。
- 支持 JSON 完整备份/恢复，CSV 导出，ICS 日历导出。
- 支持把当前复习提醒同步到本地苹果日历订阅源。

## 苹果日历同步

1. 用 `node server.js` 启动本地同步服务器。
2. 在网页“设置/导出”里点击“同步到苹果日历”。
3. 首次使用时，打开苹果日历，选择“文件 → 新建日历订阅”。
4. 输入订阅地址：

```text
http://127.0.0.1:4173/calendar.ics
```

以后每次新增学习、错题或复习结果后，再点一次“同步到苹果日历”，苹果日历会在下次刷新订阅时读到最新提醒。

## 复习规则

- 初始间隔：1 / 2 / 4 / 7 / 15 / 30 天。
- 熟记：记忆分 +15，进入更长间隔。
- 模糊：记忆分 -20，下一次复习提前。
- 完全忘了：记忆分 -40，明天复习并重启短周期。
- 非常重要和高重要性知识点复习更频繁，低重要性知识点复习间隔更长。
- 考前 14 天内，只把低分、高重要性、久未复习的内容加入重点复习。

## 数据说明

数据存储在浏览器本地 IndexedDB 中，不上传网络。建议定期在“设置/导出”中导出 JSON 备份。
